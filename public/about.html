서비스 소개 (About Batcher Tools)

웹 브라우저 기반의 100% 로컬 다기능 일괄 처리 스마트 유틸리티

배처 툴(Batcher Tools)은 디자이너, 영상 편집자, 오디오 크리에이터, 소프트웨어 엔지니어들이 일상적으로 마주치는 대용량 파일 가공 작업을 소프트웨어 설치 없이 웹 브라우저 내에서 직접 수행할 수 있도록 설계된 차세대 로컬 웹 유틸리티 도구입니다.

기존의 온라인 변환기들이 사용자의 중요한 파일을 타사 클라우드 서버로 업로드하여 처리하던 방식과 달리, 크롬(Chrome), 엣지(Edge) 등 최신 웹 표준 브라우저의 샌드박스 내부 보안 구조를 기반으로 작동합니다.

100% 로컬 브라우저 구동 (Zero-Upload & Server-less): 배처 툴은 어떠한 원본 파일 정보, 그래픽/음향 바이너리, 수정된 파일명 목록도 절대 서버로 전송하거나 외부에 보관하지 않습니다. 모든 작업은 오직 사용자의 PC 로컬 CPU/RAM 자원만을 활용하여 안전하게 실행됩니다.

제공하는 핵심 기능

SVG 대량 이미지 변환

벡터 SVG 파일을 1.0x, 1.5x, 2.0x(@2x), 3.0x(@3x) 고해상도 PNG 또는 JPG 포맷으로 순식간에 일괄 추출하여 내보냅니다.

WAV/MP3 오디오 일괄 인코딩

대용량 무압축 WAV 오디오를 브라우저 내부 코덱으로 128kbps~320kbps 맞춤 비트레이트 MP3로 초고속 일괄 인코딩합니다.

대량 파일 이름 일괄 변경 (Batch Rename)

문자열 치환, 접두/접미사, 자리수 삭제, 일련번호 부여, 정규식(Regex)을 실시간 미리보기 및 실행 취소(Undo)와 함께 지원합니다.

로컬 폴더 직접 기록 (WICG API)

File System Access API를 통해 매번 압축 ZIP 파일을 풀 필요 없이 로컬 디렉토리에 변경 결과를 직접 저장합니다.

배처 툴의 개발 철학

  • 안전한 프라이버시(Privacy First): 클라이언트 사이드 처리를 철칙으로 삼아 데이터 유출의 원인 자체를 원천 차단합니다.
  • 설치 없는 단순함(No Installation): OS나 버전 구애 없이 최신 웹 브라우저만 열면 1초 안에 사용 준비를 마칩니다.
  • 제한 없는 개방성(Free and Commercial Use): 사용량 제약이나 유료 멤버십 가입이 없습니다. 변환된 모든 결과물은 상업적/비상업적 목적으로 자유롭게 배포하고 이용할 수 있습니다.
