복잡한 프로그램 설치 없이 웹 브라우저에서 수백 개의 파일명을 한 번에 정리하세요. 문자열 바꾸기, 일련번호 매기기, 정규식 치환, 실시간 프리뷰와 실행 취소(Undo)를 완벽 지원합니다.

날짜 포맷 순서 재정렬, 특수문자 제거, 태그 추출 등 정규표현식 캡처 그룹을 활용하여 고난도 패턴을 손쉽게 치환합니다.

실시간 시각적 미리보기

규칙을 추가하거나 수정할 때마다 테이블에 변경 결과가 즉시 반영되어 실수 없이 안전하게 검토할 수 있습니다.

다단계 Undo & Reset 지원

규칙 적용이 잘못되었더라도 실행 취소(Undo)로 직전 상태로 복원하거나 원클릭으로 초기 원본 이름으로 되돌립니다.

1. 디지털 자산 관리(DAM)에서 체계적인 파일 네이밍의 중요성

디자이너, 영상 편집자, 사진작가 및 소프트웨어 개발자가 다루는 프로젝트 리소스는 수백에서 수천 개에 달합니다. `IMG_0492.JPG`, `무제_최종_진짜최종.png`, `audio_sample (1).wav`와 같이 불규칙하고 임의적인 파일 이름은 다음과 같은 심각한 생산성 저하를 유발합니다:

  • 검색 효율성 저하: 필요한 특정 날짜나 버전의 리소스를 찾기 위해 불필요한 시간을 낭비하게 됩니다.
  • 빌드 및 협업 오류: 공백(Space)이나 한글 특수문자가 포함된 파일명은 웹 서버 호스팅이나 CI/CD 배포 파이프라인에서 깨짐 현상을 일으킵니다.
  • 버전 관리 혼선: 명확한 일련번호와 접두사/접미사 규칙이 없으면 최신 파일과 구버전 파일이 덮어쓰여 데이터 유실로 이어질 수 있습니다.

배처 툴의 일괄 리네이머는 대용량 파일의 네이밍 규칙을 표준화하여 작업 흐름을 정돈하고 업무 생산성을 극대화합니다.

2. 배처 툴이 지원하는 8대 핵심 리네이밍 규칙 모드

1. 문자열 치환 (Replace)

특정 단어나 패턴을 찾아 새로운 단어로 일괄 교체합니다. (대소문자 구분 및 정규식 모드 지원)

2. 접두사 / 접미사 추가

파일명의 맨 앞이나 맨 뒤(확장자 앞)에 프로젝트명, 날짜(`2026-08_`), 버전(`_v1.0`) 등을 추가합니다.

3. 자릿수 기준 글자 삭제

앞에서 N글자 또는 뒤에서 N글자, 또는 특정 위치 범위의 불필요한 문자열을 정밀하게 잘라냅니다.

4. 괄호 및 특수문자 제거

소괄호 `()`, 대괄호 `[]`, 중괄호 `{}` 안의 텍스트를 원클릭으로 깔끔하게 소거합니다.

5. 일련번호 부여 (Auto Numbering)

시작 번호와 자릿수 패딩(`001`, `002`...)을 지정하여 정렬 순서대로 순차적인 번호를 부여합니다.

6. 확장자 일괄 변경 / 소문자화

대문자로 된 확장자(`.JPEG`, `.PNG`)를 표준 소문자로 통일하거나 포맷 확장자를 일괄 재지정합니다.

3. 실무에서 유용한 정규표현식(Regex) 활용 패턴 예시

# 날짜 구분자 통일 (YYYY-MM-DD -> YYYY_MM_DD)

검색 패턴: (\d{4})-(\d{2})-(\d{2}) / 치환: $1_$2_$3

# 대괄호 태그 및 앞뒤 공백 삭제 ([HD] video.mp4 -> video.mp4)

검색 패턴: \[.*?\]\s* / 치환: (빈 칸)

# 연속된 공백 및 하이픈을 언더스코어로 통합

검색 패턴: [\s\-_]+ / 치환: _

4. 3단계 파일 리네이밍 가이드

STEP 01 대상 파일 로드

이름을 변경할 파일들을 끌어다 놓거나 '폴더 선택'으로 폴더를 지정합니다.

STEP 02 규칙 설정 & 미리보기

치환/일련번호 등 규칙을 추가하고 오른쪽 '변경될 이름' 열에서 실시간 결과를 확인합니다.

STEP 03 일괄 적용 완료

'이름 변경 적용'을 누르면 로컬 파일 이름이 1초 만에 안전하게 일괄 수정됩니다.

자주 묻는 질문 (FAQ)

파일 이름 일괄 변경과 안전장치에 관한 질문들을 확인해 보세요.

변경 버튼을 누르기 전까지는 원본 파일이 유지되나요?

네, 규칙을 추가하거나 수정하는 동안에는 브라우저 메모리 상에서 가상으로만 계산되어 '변경될 이름' 열에 미리보기로 표시됩니다. 하단의 초록색 '이름 변경 적용' 버튼을 최종 클릭해야만 실제 로컬 디스크의 파일명이 업데이트됩니다.

실수로 원치 않는 규칙을 적용했을 때 되돌릴 수 있나요?

상단의 'Undo (실행 취소)' 버튼을 누르면 직전 규칙 적용 상태로 즉시 되돌릴 수 있으며, 여러 규칙이 복잡하게 얽힌 경우 'Reset (초기화)' 버튼을 눌러 처음 로드했던 원본 파일명 상태로 즉시 복원할 수 있습니다.

상업적 업무 프로젝트나 회사 PC에서 사용해도 안전한가요?

배처 툴은 100% 클라이언트 사이드에서 작동하며 어떠한 서버 통신도 발생하지 않습니다. 회사 내부 기밀 문서나 고객 데이터가 외부로 유출될 위험이 전무하며, 상업적/개인적 용도 모두 완전 무료로 자유롭게 사용 가능합니다.
