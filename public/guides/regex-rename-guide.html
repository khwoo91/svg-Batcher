정규표현식(Regex)을 이용한 대량 파일 이름 일괄 변경 가이드

최종 갱신: 2026년 8월 24일 읽는 시간: 약 7분 대상: 개발자, 데이터 관리자

단순한 단어 치환(Search & Replace) 기능만으로는 날짜 순서를 뒤바꾸거나, 특정 패턴의 숫자만 추출하거나, 불규칙한 구분 기호를 일괄 정리하기 어렵습니다. 이럴 때 정규표현식(Regular Expression, Regex)을 활용하면 아무리 복잡하고 까다로운 파일 이름 패턴이라도 단 한 줄의 수식으로 완벽히 재구성할 수 있습니다.

핵심 개념: 괄호 ()를 사용해 그룹을 묶고, 치환 문자열에서 $1, $2 백레퍼런스(Backreference)를 사용하면 캡처된 텍스트의 순서를 자유자재로 재배치할 수 있습니다.

1. 실무에서 가장 많이 쓰이는 정규식 패턴 4선

1) 날짜 포맷 순서 재정렬 (YYYY-MM-DD -> YYYY_MM_DD)

연-월-일 사이에 들어간 하이픈을 언더스코어로 통일하거나, 일-월-연 순서(DD-MM-YYYY)를 표준 규격으로 변경할 때 유용합니다.

검색 패턴 (Regex): (\d{4})-(\d{2})-(\d{2})
치환 패턴 (Replace): $1_$2_$3
결과: 2026-08-24_log.txt -> 2026_08_24_log.txt

2) 대괄호 및 태그 텍스트 일괄 삭제

다운로드한 미디어 파일에 포함된 [HD], [720p], [1080p] 등의 불필요한 태그를 통째로 지웁니다.

검색 패턴 (Regex): \[.*?\]\s*
치환 패턴 (Replace): (빈 칸으로 둠)
결과: [HD] sample_video.mp4 -> sample_video.mp4

3) 연속된 공백 및 특수문자를 언더스코어(_)로 통일

웹 서버 업로드 시 URL 인코딩 에러를 유발하는 스페이스(공백)와 특수기호를 깔끔한 언더스코어로 정리합니다.

검색 패턴 (Regex): [\s\-_]+
치환 패턴 (Replace): _
결과: my cool - photo 01.jpg -> my_cool_photo_01.jpg

4) 파일명 뒤에 붙은 중복 복사본 번호 정리

윈도우에서 복사 시 자동 생성되는 - 복사본 (2), (1) 등의 텍스트를 제거합니다.

검색 패턴 (Regex): \s*[-_]?\s*복사본(\s*\(\d+\))?|\s*\(\d+\)
치환 패턴 (Replace): (빈 칸)
결과: 문서 - 복사본 (2).docx -> 문서.docx

2. 배처 툴에서 정규식을 사용하는 방법

  1. 대량 파일 리네이머 페이지에 접속하여 대상 파일을 로드합니다.
  2. 규칙 유형에서 '문자열 치환(Replace)'을 선택하고, '정규식(Regex) 사용' 체크박스를 켭니다.
  3. 검색할 정규식 패턴과 치환 패턴(예: $1_$2)을 입력합니다.
  4. 테이블에서 실시간 미리보기를 확인한 뒤 '이름 변경 적용'을 클릭합니다.
